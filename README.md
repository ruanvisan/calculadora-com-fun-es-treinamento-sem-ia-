como usar

primerio o codigo ira pedir o primeiro numero

segundo ira pedir os segundo

terceiro ira pedir um numero para uma das operaçoes (somar, subtrair, mutiplicar, ou dividir)

caso esteja tudo certo (valor do primeiro e segundo forem int, e o terceiro algo entre 1 a 4 para a escolha)
ira mostrar a operação e depois o resultado, caso seja um numero dividido por 0 ira mostrar não é possivel dividir por 0
caso não for como mencionado antes ira printar mensagem de erro

como queria testar função fiz apenas com int
